# Jumbo Steel Mills

Website for Jumbo Steel Mills Limited — steel, tanks, roofing and building materials, Rabai, Kilifi County, Kenya.

Built with TanStack Start (React 19), Vite, Tailwind CSS 4 and Nitro. Hosted on Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The Nitro `vercel` preset writes the deployable output to `.vercel/output`.

## Deploy

Import the repository in Vercel and deploy with the default settings. No environment variables are required.

Optional: set `VITE_SITE_URL` (for example `https://www.example.com`) so social link previews use an absolute image URL.
